# ユビキタス言語表（倉庫在庫管理）

> この表を **用語の正**とする。コード・ドキュメント・会話で表記を揃える
> （[`.claude/rules/ddd-ubiquitous-language.md`](../.claude/rules/ddd-ubiquitous-language.md)）。
> 由来: [`event-storming/`](event-storming/) の分析成果物。

## 中核概念（名詞・集約・値オブジェクト）
| 日本語 | 英名（コード） | 種別 | 意味 |
|---|---|---|---|
| 在庫アイテム | `InventoryItem` | 集約（コア） | SKU × ロケーション単位の在庫。不変条件 引当可能＝手持在庫−引当済≥0 を守る |
| 入荷ロット | `InboundReceipt` | 集約 | 受入ドックに届いた、まだロケーション未確定の在庫のかたまり |
| 出荷 | `Shipment` | 集約 | 出荷指示〜ピッキング〜出荷の工程・状態 |
| 棚卸 | `Stocktake` | 集約 | 実地棚卸の対象・カウント・差異 |
| SKU | `Sku` | 値オブジェクト | 商品識別（Stock Keeping Unit） |
| ロケーション | `LocationId` | 値オブジェクト | 倉庫内の物理ロケーション（棚マス等） |
| 数量 | `Quantity` | 値オブジェクト | 非負整数。加減算・`≥` 比較を持つ |
| 手持在庫 | `onHand` | 状態（`Quantity`） | 物理的に手元にある数量 |
| 引当済 | `allocated` | 状態（`Quantity`） | 予約済み（出荷に向け確保）の数量 |
| 引当可能 | `available` | 導出値 | 手持在庫 − 引当済。引当可能な残り |

## コマンド（命令形の動詞）
| 日本語 | 英名 | 対象集約 | 意味 |
|---|---|---|---|
| 入荷する | `ReceiveStock` | 入荷ロット | 受入ドックに在庫を受け入れる |
| 検品する | `InspectStock` ❓ | 入荷ロット | 合否を判定（独立化は保留 H8） |
| 格納する | `PutAwayStock` | 入荷ロット | ロケーションを選定して格納する |
| 在庫を計上する | `PlaceStock` | 在庫アイテム | 格納の結果、在庫アイテムへ手持在庫を加える（ポリシーP1） |
| 引き当てる | `AllocateStock` | 在庫アイテム | 引当可能の範囲で在庫を予約する |
| 引当を解除する | `DeallocateStock` | 在庫アイテム | 予約を取り消す |
| 出荷を指示する | `RequestShipment` ❓ | 出荷 | 出荷を要求（外部トリガ扱い・H9） |
| ピッキングする | `PickStock` | 出荷・在庫アイテム | 棚から取り出す |
| 出荷する | `ShipStock` | 出荷 | 出荷を完了する |
| 棚卸を開始する | `StartStocktake` | 棚卸 | 対象範囲を確定し棚卸を始める |
| カウントする | `CountStock` | 棚卸 | 実地数量を記録する |
| 在庫を調整する | `AdjustStock` | 在庫アイテム | 実地差異を在庫へ補正する（ポリシーP4） |

## イベント（過去形・完了した事実）
| 日本語 | 英名 | 発生集約 | 意味 |
|---|---|---|---|
| 在庫が入荷された | `StockReceived` | 入荷ロット | 受入ドックに在庫が届いた（ロケーション未確定・引当不可） |
| 在庫が検品された | `StockInspected` ❓ | 入荷ロット | 検品の合否が確定した（保留 H8） |
| 在庫が格納された | `StockPutAway` | 入荷ロット | ロケーションが確定し受入ロットから引き落とされた |
| 在庫が計上された | `StockPlaced` | 在庫アイテム | 在庫アイテムに手持在庫が加わり引当可能化した |
| 在庫が引き当てられた | `StockAllocated` | 在庫アイテム | 引当可能から予約が確保された |
| 引当が解除された | `StockDeallocated` | 在庫アイテム | 予約が取り消された |
| 出荷が指示された | `ShipmentRequested` ❓ | 外部・出荷 | 出荷が要求された（外部トリガ扱い・H9） |
| 在庫がピッキングされた | `StockPicked` | 出荷・在庫アイテム | 棚から取り出された |
| 在庫が出荷された | `StockShipped` | 出荷 | 出荷が完了した |
| 棚卸が開始された | `StocktakeStarted` | 棚卸 | 棚卸の対象範囲が確定した |
| 実地数量がカウントされた | `StockCounted` | 棚卸 | 実地数量が記録された |
| 在庫差異が記録された | `StockDiscrepancyRecorded` | 棚卸 | 帳簿値と実地値の差が確定した |
| 在庫が調整された | `StockAdjusted` | 在庫アイテム | 手持在庫が実地値へ補正された |
| 在庫がロケーション間で移動された | `StockMoved` ❓ | 在庫アイテム | 別ロケーションへ移動した（M3+改修候補・H5） |

## ポリシー / リードモデル
| 日本語 | 英名 | 種別 | 意味 |
|---|---|---|---|
| 格納伝播ポリシー | `PutawayProcess`（P1） | ポリシー/Saga | 在庫が格納された→在庫を計上する。受入ロット→在庫アイテム |
| 引当ポリシー | `AllocationPolicy`（P2） | ポリシー（コア） | 受注→引当可能在庫ビュー参照→引当先選定→引き当てる |
| 出荷プロセス | `FulfillmentProcess`（P3） | ポリシー/Saga | 出荷指示/引当→ピッキング/出荷 |
| 棚卸調整ポリシー | `AdjustmentPolicy`（P4） | ポリシー | 在庫差異が記録された→在庫を調整する |
| 引当可能在庫ビュー | `AvailableStockView` | リードモデル | SKU×ロケーション別の引当可能数 |
| 引当ビュー | `AllocationView` | リードモデル | 引当の一覧（出荷・取消の入力） |
| 在庫元帳ビュー | `StockLedgerView` | リードモデル | 全在庫変動の履歴（ES の履歴の旨味を可視化） |

> ❓ = 保留・暫定（M2 戦術設計で確定）。詳細は [`event-storming/03-software-design.md`](event-storming/03-software-design.md) の未決一覧を参照。
